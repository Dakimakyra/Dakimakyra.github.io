ДОС 20 — мобильный сайт-поздравление (ДОС 19 — внутренняя шутка)

Как открыть:
1. Распакуйте ZIP полностью.
2. Откройте index.html в браузере (Chrome, Safari и т.п.).
3. Для отправки ссылкой на телефон разместите содержимое папки dos19 на хостинге, например Netlify Drop: https://app.netlify.com/drop (перетащите папку с index.html и assets).

Управление: свайпните котика вправо (или нажмите кнопку), затем нажмите на открывшееся фото. Дальше листайте сайт, открывайте фотки, играйте.

Все фотографии находятся в папке assets, приложение работает без сервера. Шрифты из Google Fonts требуют интернет, но при их отсутствии используются системные.
